- facepart 명시 1~8: 이마, 미간, 오른쪽 눈가, 왼쪽 눈가, 오른쪽 볼, 왼쪽 볼, 입술, 턱. 부위별 전문가 평가가 있어도 실제 항목과 기준은 JSON 및 가이드 확인 필요.

## 중요: 발표 통계 단위 불일치

공식 표에는 13,936장의 사진과 125,424건의 주석이 나타난다. 얼굴 부위 표는 13,936 × 9 = 125,424건으로 계산 가능하나, 촬영 각도 표에서는 9,648 × 13 = 125,424건으로 표시한다. 같은 수치를 **독립 사진 수 또는 피험자 수라고 간주할 수 없다**. 실제 파일에서 distinct filename / id / angle / facepart 및 조인 관계를 확인하고, id가 사람 ID인지 행 ID인지 확인한다.

## 신청자가 해야 할 접근 절차

1. 국내 신청자 자격으로 사이트 로그인/회원가입과 휴대전화 본인인증.
2. 데이터 페이지의 다운로드 클릭 → 신청 목적 작성 → 실제 표시된 조건을 읽고 동의 후 신청.
3. FAQ에는 휴대폰 인증 완료 사용자의 다운로드 자동승인 경로가 안내돼 있으나 **해당 데이터셋에 그대로 적용되는지 승인 화면 확인**.
4. 데이터 설명서, 구축활용가이드, 라벨 JSON/측정 CSV 및 최소 샘플을 우선 확보. 대량 원본 JPG 다운로드보다 구조 점검 우선.
5. 승인 조건/버전/다운로드 화면 증빙을 승인된 안전한 저장소에 보관. API Key, 로그인 토큰, 얼굴 원본은 Git 또는 외부 공개 채팅에 업로드 금지.
6. 안심존으로만 접근할 수 있다는 안내가 나오면 안심존 승인 경로를 따르고 승인 범위 밖 반출 금지.

BEJEWELY의 비의료적 피부 이미지 분석 연구개발을 위해 안면 사진과 피부 측정값의 연결을 검증하고, 모공 가시성·색소·표면 특징 관찰 모델의 성능 평가 및 학습에 활용하려고 합니다. 원본 이미지의 무단 재배포나 국외 반출 없이, 제공 조건이 허용하는 범위에서만 이용하겠습니다. 여드름 병변 좌표 또는 홍조/색소 영역의 추가 전문가 주석 제작에 관한 허용 범위는 별도로 확인하겠습니다.

## 승인 후 데이터 검사

저장소 루트에서 실행:

    node scripts/audit-aihub-71645-metadata.mjs --self-test
    node scripts/audit-aihub-71645-metadata.mjs "C:\private\aihub71645\labels" --max-files=200

이 검사는 JSON만 읽고 JPG 원본을 읽지 않으며, ID/이름/파일명/생년월일을 출력하지 않는다. 행 수, 이미지 파일명 후보 수, 반복, face_box 범위, facepart 분포, 각 피부 측정 필드의 결측 현황만 집계한다. CSV는 아직 지원하지 않으므로 측정값 JSON과 CSV 연결 검증이 완료됐다고 보고하지 않는다.

권리 조건을 충족하지 못하면 실제 사진을 도입/복사/재라벨링하지 않는다. 공개 설명의 source field가 실제 파일과 다르면 검사기 보정 전까지 통계 해석을 중단한다.
