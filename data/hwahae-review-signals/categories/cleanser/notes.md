## 3. 가장 중요한 운영 원칙

클렌저 리뷰 신호는 **좋고 나쁨의 절대 점수**가 아니다.

클렌저는 제품마다 세정 강도, 잔여감, 보습감, 거품감, 자극 가능성이 다르기 때문에 리뷰 키워드를 아래 용도로만 사용한다.

```txt
1. cleansing_profile 추정
2. 사용자 조건별 적합/부적합 신호 분리
3. 자극/알러지/따가움 리스크 감지
4. 결과 설명 문구 보강
5. 동점자 판별 또는 confidence 표시
```

금지:

```txt
review_count를 Top Pick 점수에 직접 크게 반영하지 말 것
rating 5.0을 고품질 확정 신호로 쓰지 말 것
negative count를 절대값만 보고 감점하지 말 것
세정안되는/미끌거리는을 모든 사용자에게 단점으로 처리하지 말 것
세정잘되는/뽀드득거리는을 모든 사용자에게 장점으로 처리하지 말 것
```

## 4. review_count / rating 사용 규칙

리뷰 수와 평점은 추천 본체가 아니라 **검증도와 confidence**로만 사용한다.

```txt
review_count < 100     -> low confidence
100 ~ 999              -> medium confidence
1,000 ~ 9,999          -> high confidence
10,000+                -> very_high confidence
```

예시:

```txt
아토베리어365 포밍 클렌저
- review_count: 18
- rating: 5.0
- 해석: 사용자 조건에 맞을 수는 있지만 표본이 매우 작다. 평점 5.0을 직접 점수화하면 과대평가된다.
```

```txt
1025 독도 클렌저
- review_count: 19,014
- rating: 4.36
- 해석: 대중 검증도는 높지만 세정안되는/미끌거리는/노폐물제거안되는 신호가 강하다. 세정력을 원하는 사용자에게는 감점될 수 있다.
```

## 6. negative 키워드 해석 주의

클렌저에서 negative는 두 종류로 나눈다.

### A. 취향/세정 강도 mismatch

```txt
세정안되는
노폐물제거안되는
뽀드득거리지않는
미끌거리는
거품안나는
거품이풍성하지않은
워터프루프안지워지는
잔여물남는
```

이것은 모든 사용자에게 단점이 아니다.

- 건성/민감성 사용자에게는 순한 세정의 반대급부일 수 있다.
- 지성/피지/모공/강세정 선호 사용자에게는 명확한 감점이다.

### B. 실제 리스크

```txt
알러지반응오는
자극있는
따가운
가려운
트러블생기는
뒤집어지는
눈통증있는
```

이것은 민감성/붉은기/장벽 약한 사용자에게 강하게 감점한다.

단, review_count가 매우 작고 count가 1~2 수준이면 과대 반영하지 않는다.

## 7. ingredient_raw 사용 규칙

성분 신호는 보조 근거다.

```txt
risk.high > 0
→ 민감성 추천에서 보수적으로 본다.

risk.low 비중이 높고 high = 0
→ irritation_risk low 후보지만, 리뷰 negative 자극 신호와 함께 본다.

functional.skin hydration 높음
→ dehydration / moisture 계열 보조 근거.

functional.exfoliation 높음
→ pores / acne / deep_clean 보조 가능. 단 민감성에는 자극 가능성도 같이 본다.
```

주의:

```txt
성분 위험도만으로 sensitivity_safe = true 확정 금지
skin_type 성분 신호만으로 skin_types 확정 금지
```

## 8. 제품별 1차 해석 메모

### 약산성 굿모닝 젤 클렌저

- 약산성/자극 없음/보습/2차 세안 신호.
- 세정안되는/미끌거리는/노폐물 제거 안되는 신호가 있어 강세정 목적에는 약하다.
- low_ph_moisture 후보.

### 다이브인 저분자 히알루론산 클렌징 폼

- 보습/수분/약산성/트러블 안 생김 신호가 매우 강하다.
- 노폐물 제거/워터프루프/피지 제거 불만이 있어 강세정 목적에는 약하다.
- low_ph_moisture 후보.

### 아토베리어365 포밍 클렌저

- 리뷰 18개로 표본이 매우 작다.
- 평점 5.0을 점수로 직접 쓰면 안 된다.
- 성분/포지션상 건성/장벽/민감성 후보로 볼 수 있으나 confidence는 low.

### 약산성 레드 블레미쉬 클리어 수딩 폼

- 자극 없음/약산성/진정/트러블 완화 신호.
- high risk 성분 1개와 sensitive negative 성분 신호가 있어 민감성 안전 확정은 보수적으로.
- low_ph_moisture 또는 balanced 후보.

### 화산송이 모공 바하

- 세정/거품/뽀득/모공/각질/피지 신호가 강하다.
- 보습 안됨/따가움/알러지/가려움 신호가 있어 민감·건성에는 감점.
- deep_clean 후보.

### 자작나무 수분 클렌저

- 자극 없음/수분/보습/약산성 신호가 강하다.
- 세정안됨/거품안남/미끌거림 불만이 있어 강세정 목적에는 약하다.
- low_ph_moisture 후보.

### 똘러리앙 퓨리파잉 포밍 클렌저

- 세정/자극 없음/거품/보습이 같이 잡힌다.
- 평점 5.0이지만 리뷰 346개라 절대 우위로 보면 안 된다.
- 알러지/따가움/가려움/눈통증 신호가 있어 민감성 최우선 추천은 보수적으로.
- balanced 후보.

### 녹두 클렌징폼

- 트러블/각질/진정/2차 세안 신호가 강하다.
- 알갱이, 각질 제거 신호가 있어 물리적/체감 자극 가능성을 봐야 한다.
- 리뷰 수가 매우 많아 검증도는 높지만, 알러지/가려움도 존재한다.
- acne/pores 쪽 후보지만 민감성에는 주의.

### 1025 독도 클렌저

- 보습/약산성/수분/트러블 안 생김 신호가 강하다.
- 세정안됨/미끌거림/노폐물 제거 안됨/잔여물 남음 신호도 매우 강하다.
- 대중 검증도는 높지만 강세정 목적에는 부적합.
- low_ph_moisture 후보.

### 퍼펙트 휩 페이셜 워시

- 세정/거품/뽀득/화장 지움/유분 없음 신호가 강하다.
- 보습 안됨/자극/트러블/따가움/수분 없음 신호가 크다.
- deep_clean 후보.
- 건성/민감성/장벽 약한 사용자에게는 강한 감점.

## 9. 추천 로직 적용 원칙

Top Pick 산식에서 클렌저는 아래 우선순위를 따른다.

```txt
1. 사용자 피부타입/주고민 적합도
2. cleansing_profile 적합도
3. 자극/알러지/따가움 risk_score
4. 사용 목적: 아침 세안 / 2차 세안 / 강세정 / 피지 모공
5. review_count는 confidence 또는 동점자 판별
6. rating은 낮은 경우 감점 참고, 높은 경우 직접 가산 금지
```

추천 예시:

```txt
건성 + 민감 + 세안 후 당김 싫음
→ low_ph_moisture 우선
→ deep_clean 제외 또는 강한 감점
```

```txt
지성 + 피지/모공 + 뽀득한 세안 선호
→ deep_clean 후보 허용
→ low_ph_moisture는 세정력 불만 신호 확인 후 감점
```

```txt
복합성 + 자극 걱정 + 적당한 세정력
→ balanced 또는 low_ph_moisture 중 risk 낮은 제품
```

## 10. 배치 파일 사용 주의

- 배치 파일 안의 `estimated_cleansing_profile`은 자동 요약용 임시값이다.
- 최종 DB 반영 전에는 코덱스/사람 검토를 거친다.
- raw JSON은 원본 근거로 보존한다.
- `category`가 없던 원본은 배치 wrapper에서 `cleanser`로 보강했다.
- 매핑 로직이 바뀌면 raw JSON 기준으로 재처리한다.

## 11. 한 줄 결론

클렌저 리뷰 신호는 제품의 절대 우열을 정하는 데이터가 아니라, **세정 강도·보습감·잔여감·자극 리스크·사용자 취향 적합성**을 분류하기 위한 신호다.
