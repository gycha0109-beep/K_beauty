## 우선순위 권위 경계

우선순위는 가중 점수가 아니라 사전순 규칙이다.

1. 배리어·탈수 관련 사용자 상황 도달 범위
2. 명시적으로 `is_primary_moisturizer=true`인 기존 카탈로그 문맥
3. 기존 소스 조사 단서
4. 같은 구간 안에서 리뷰 수를 시장 관심도 동률 해소용으로만 사용
5. 최종 동률은 상품 ID

화해 바인딩, 기존 `source_url`, 바인딩 URL은 **공식 사실 권위가 아니다**. 단지 연구 시작점을 찾기 위한 단서다. 리뷰 수는 Product Fact 참/거짓, 효능, 추천 점수 또는 추천 자격에 사용하지 않는다. `recommendation_tier`는 추적용으로만 보존하고 정렬에 사용하지 않는다.
