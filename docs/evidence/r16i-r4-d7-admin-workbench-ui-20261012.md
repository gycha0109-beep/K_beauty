# R16I-R4-D7 — 관리자 화면 운영형 개편 (2026-10-12)

## 목표
기존 R16I-D5의 20개 DB 필드 전개 화면을 **운영자가 지금 해야 할 행동 중심**의 상품 정정 작업대로 변경. 비주얼 시안 승인 범위에서 UI만 재배치하며 기존 D4 reader/권한/출처/Offer/Subject/추천 로직 유지.

## 확정 화면 구조

1. **현재 문제:** D4의 실시간 조회한 160ml/29,900원/레거시 리뷰수 출력. 정체성 혼재와 근거 부족 설명. DB drift 발생 시 D4 `BLOCKED` 경고만 출력하고 레거시 수치, 검토 표 및 메모 복사 숨김.
2. **판매처별 실제 정보 확인:** 공식 80ml 단품과 화해 80ml×2+세럼10ml 별도 카드. 원본 상품 페이지 외부 링크, 확인 체크리스트와 각 2개 현장 노트. 상품 사진·가격·리뷰를 실제 원본/결제 증명 없이 만들어 보여주지 않음.
3. **정정안 미리보기:** 원본 D4 prestate의 저장값과 A안 구조적 분리 방향 비교. after 값은 미승인/미확정. 160→80 자동 변환·29,900원 자동 이전·Offer/Subject 발급 전면 금지.
4. **확인한 원본 근거 기록:** 세럼 SKU·원본 캡처 저장위치와 리뷰 귀속 선택적 조사 메모. 7개 필드는 기존 JSON 계약 유지, 사용자가 직접 입력한 내용만 메모리 상태로 관리. **복사만 가능**; 서버 저장/첨부/검증/인증/운영 승인 불가. 첨부는 [#1204](https://github.com/gycha0109-beep/K_beauty/issues/1204)에서 진행.
5. **최종 검토 상태:** 근거 미충족으로 정정 검토 요청 버튼은 disabled; 임시 저장, 보류 승인, 증빙 자동 인증 기능을 구현한 것처럼 가장하지 않음.
6. **기술 상세:** 기존 20개 필드의 실제 before 값 및 보류 사유를 원형 데이터로 표시하되 기본 접힘 `details/summary`.
