## 이번 추가 구현

- `lib/trust/cleanser-r5-private-source-drift-guard-v1.mjs`: 10개 상품을 기존 축약 스냅샷과 비교하여 다른 상품 ID/카테고리/제형 변화, 화해 출처/URL 문자열 불일치, 리뷰 수·매핑된 AI 요약 항목 개수, 성분 피부/기능/위험 집계 **키 개수** 변경이 있으면 즉시 중단한다.
- `scripts/run-cleanser-r5-private-full-engine-readonly-v1.mjs`: 서버 전용 실제 원본 164+10 전체 엔진 검사 앞에 위 확인을 추가했다. 공용 CI와 서비스 인증정보 없는 실행은 계속 금지한다.
- `scripts/verify-cleanser-r5-private-source-drift-guard-v1.mjs`: 외부 네트워크/원본 없이 기존 축약 자료로 정상 10개·허위 변경 반례를 검증한다. Current Main Health에 등록했다.

**검증 범위의 한계:** 집계 항목 개수와 URL 문자열이 같아도 각 신호의 실제 값/원본 페이지 내용은 바뀌었을 수 있다. 이 검사는 **내용 전체의 해시 검증·수집권·정확한 한국 상품 인증이 아니다**. 최종 추천 점수·순위로 사용하면 안 된다.
