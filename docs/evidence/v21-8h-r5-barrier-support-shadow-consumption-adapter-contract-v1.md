# V2.1-8H-R5 — 배리어 지원 그림자 추천 소비 어댑터 계약

## 종료 판정

`BARRIER_SUPPORT_SHADOW_CONSUMPTION_ADAPTER_CONTRACT_FROZEN`

5단계는 4단계에서 검증된 비수치형 배리어 지원 의사결정축을 사용자 배리어·탈수 문맥과 연결하기 위한 **계약만 고정**한다. 실제 실행 경로 연결은 6단계 책임이다.

## 입력 경계

상품 쪽 입력은 4단계 출력의 진릿값, 사용 역할 문맥, 적용 범위, 불확실성, 범위 해석 상태, 계보를 그대로 소비한다.

사용자 쪽 입력은 외부 문맥의 `concern_axes`만 사용한다. 배리어 지원축과 관련 있는 사용자 축은 `barrier`, `dehydration` 두 개뿐이다.

- `barrier` 또는 `dehydration`이 있으면 관련 있음
- 둘 다 있어도 하나의 비가산 문맥일 뿐 점수 단위가 늘지 않음
- `redness`만으로는 배리어 지원축 관련성을 만들지 않음
- 사용자 문맥이 없으면 관련성도 미확정으로 유지

## 상품 사실 의미론

- 참: 공식 배리어 지원 주장이 확인됨
- 거짓: 명시적 부정 주장 상태가 확인됨
- 미확정: 거짓으로 바꾸지 않음
- 차단: 미확정으로 완화하지 않음
- 비적용: 그대로 비적용
- 사용 역할: 문맥일 뿐 효능·강도·자격을 바꾸지 않음

특히 `local_area`를 전면 사용 부적합으로 해석하지 않고, `full_face`를 더 강한 제품으로 해석하지 않는다.

## 출력 경계

허용되는 출력은 주장 존재 상태, 사용자 관련성, 관련 사용자 축, 사용 역할 문맥, 주석 권위 상태, 적용 범위, 불확실성, 범위 상태, 계보다.

항상 다음을 유지한다.

- 숫자 기여: `null`
- 순위 영향: `NONE`
- 후보 자격 영향: `NONE`

참 + 관련 문맥에서는 `positive_claim_context_available`, 명시적 거짓 + 관련 문맥에서는 `explicit_negative_claim_context_available`만 낸다. 이것은 추천 판정이 아니라 **설명용 그림자 입력 권위**다.

## 금지

점수 가산·감점, 순위 변경, 후보 자격·승인 변경, 선호 슬롯 강제, 강약 추정, 장벽 개선량 추정, 안전성·적합성 추정, 사용 역할 기반 전면/국소 적합성 판정, 범위 자동 선택, 배리어+탈수 이중 가산, 기존 배리어 경로와의 가산 결합, 공개 추천 변경을 금지한다.

## 회귀 경계

기존 승인 후보 164개 × 사용자 상황 12개 = 1,968건의 추천 불변성은 그대로 유지한다. 5단계에서는 실행 경로를 연결하지 않으므로 운영 추천 소비는 `NO`, 추천 활성화도 `NO`다.
