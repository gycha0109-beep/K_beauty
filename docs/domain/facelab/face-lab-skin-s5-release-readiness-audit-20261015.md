## 이번 검사의 두 문턱

1. **제품 완성도:** 코드/구조 감사, 실제 사진의 독립 정확도, 설문과 제품 판단 안전성, 반복 촬영 신뢰성, 휴대폰·웹 사용성 평가를 각각 확인한다.
2. **출시 가능 여부:** 공급망 보안, 개인정보 촬영동의/철회/보유기간, 계정별 접근·저장 권한, 필수 자동 점검, 장애 대응·되돌리기, 책임자 승인을 별도 확인한다.

아직 증거가 없는 항목은 **보류**로 남기고, 명확히 실패한 항목은 **차단**으로 남긴다. 모든 항목이 문서상 통과로 입력되더라도 실제 근거 확인·책임자 승인 없이는 어떤 배포 승인도 내보내지 않는다. 항목에 적은 참조 문자열은 단순 식별자이지 실제 승인서가 아님을 코드에서 명시한다.

## 현재 안전 차단

- #1208 공급망 취약점 차단: 2026-10-14 확인 시 `braces@3.0.3` 관련 허용 기한 만료로 보안 점검 실패. 이 세션에서 예외 기한을 연장하거나 허용 범위를 변경하지 않는다.
- 실제 얼굴 사진의 동의·비공개 보관·삭제·재활용 권한 및 반복 촬영 비교는 아직 승인된 근거가 없다.
- 피부 사진 분석 정확도·인간 평가·실기기 촬영의 외부 검증이 수행되었다고 보고하지 않는다.
- #1313 휴대폰 점검에서 기존 카메라 점검과 워크플로 구조가 다른 별도 문제가 남아 있다. 해당 모바일 오너의 확인 없이 점검 기준을 완화하지 않는다.
- 여러 Draft PR은 main에 병합되지 않았다. 성공한 검증은 **해당 PR의 코드**에 대한 검증이지 현재 서비스가 이미 수정되었다는 뜻이 아니다.

## 검증 방법

`node scripts/facelab/skin/verify-face-lab-skin-s5-readiness.mjs`

입력 항목이 없을 때 보류, 실제 보안 실패가 있을 때 차단, 사용자 사진 증거 대신 합성 증거를 넣을 때 거절, 문서상 모든 항목 통과를 가정하더라도 출시 승인은 여전히 거절되는지 확인한다. 기존 공통 점검에 한 건의 개발용 검사만 추가한다. 별도의 운영 배포, 실제 정보 저장, 사진 제공 요구, 새 외부 호출은 없다.

- 제품 완성도 승인: 실사진·전문 평가·반복성·사용자 경험·판단 안전성에서 책임자가 확인한 실제 근거 필요.
