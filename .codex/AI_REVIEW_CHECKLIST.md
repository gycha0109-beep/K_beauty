# AI_REVIEW_CHECKLIST.md

## 공통 검증

- 프로젝트의 기본 빌드/테스트/실행 명령이 통과했는가
- 핵심 사용 흐름이 유지되는가
- 주요 사용자 액션이 유지되는가
- 주요 화면 또는 결과물이 정상 표시되는가
- 런타임 에러, 콘솔 에러, 예외 로그가 없는가
- 기존 데이터 구조나 응답 구조와 호환되는가
- 인증, 권한, 저장, 결제, 외부 연동 등 보호 구역에 영향이 없는가
- 요청 범위를 벗어난 변경이 없는가

## UI/UX 작업 검증

- 변경 목적이 실제 화면에서 해결되었는가
- 정보 위계가 명확한가
- 텍스트 밀도가 과하지 않은가
- 주요 액션이 사라지거나 약해지지 않았는가
- 주요 상태값이 사용자에게 명확히 전달되는가
- 반응형 화면 또는 주요 사용 환경에서 깨지지 않는가
- 접근성, 대비, 터치/클릭 가능 영역에 문제가 없는가

---

## API/데이터 작업 검증

- 기존 호출부와 호환되는가
- 필드명, 타입, 응답 구조가 의도 없이 변경되지 않았는가
- null/undefined/empty/error fallback이 있는가
- 기존 저장 데이터와 충돌하지 않는가
- DB/외부 서비스 요청이 의도한 범위만 조회/수정하는가
- 실패 응답이나 예외 상황이 처리되는가
- 권한, 인증, 환경 변수, 배포 설정에 의도치 않은 영향이 없는가

---

## AI/자동 생성 결과물 검증

- 결과가 너무 일반론적이지 않은가
- 입력값이나 사용자 조건이 실제 결과에 반영되는가
- 권한, 상태, 플랜, 조건별 결과 차이가 명확한가
- 반복 표현이 과하지 않은가
- 위험하거나 부정확한 내용이 없는가
- 출력 형식이 기존 소비 코드나 문서 구조와 호환되는가
- 실패, 누락, 파싱 오류에 대한 fallback이 있는가

---

## 문서/규칙 작업 검증

- 기존 문서와 중복되는 내용이 없는가
- 특정 프로젝트에만 해당하는 표현이 공용 규칙에 들어가지 않았는가
- 규칙의 우선순위가 충돌하지 않는가
- 너무 자세한 설명이 상위 문서에 들어가지 않았는가
- 반복 규칙과 일회성 작업 기록이 분리되어 있는가
- 폐기된 방향이나 오래된 기준이 되살아나지 않았는가
